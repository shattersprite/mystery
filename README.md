# 🕵️ Mystery

**Turn your Minecraft server into a mystery waiting to be solved.**

Mystery is a powerful, easy-to-use adventure framework for Paper servers that lets you create **interactive mysteries, clue hunts, puzzles, scavenger hunts, and story-driven adventures** without writing Java code.

Hide clues around your world. Create puzzles. Build branching paths. Reward players for solving the mystery. Then sit back and watch your players investigate. 🔎

## ✦ Features

* 🕵️ **Interactive Mysteries** — Build multi-stage investigations and adventures.
* 📜 **Clue System** — Deliver clues through chat, books, items, titles, sounds, and more.
* 🧩 **Modular Puzzles** — Create codes, passwords, word puzzles, sequences, and custom challenges.
* 📍 **Location Triggers** — Hide discoveries throughout your Minecraft world.
* 🌿 **Branching Paths** — Let player choices determine where the mystery goes.
* 💡 **Hints** — Give players optional hints when they get stuck.
* 👥 **Multiplayer Support** — Create individual, team, first-completion, or server-wide mysteries.
* 🎁 **Custom Rewards** — Reward players with items, XP, commands, permissions, and more.
* 🛠️ **In-Game Editor** — Create and configure mysteries directly from Minecraft.
* 🧪 **Testing Mode** — Test your mysteries before releasing them to players.
* 💾 **Persistent Progress** — Player progress survives disconnects and server restarts.
* 📦 **Shareable Mysteries** — Export and import mystery files between servers.
* 🔌 **Developer API** — Extend Mystery with custom puzzles, stages, rewards, and integrations.
* ⚡ **Lightweight** — Designed to be efficient and friendly to performance.
* 🎨 **Highly Configurable** — Customize messages, effects, rewards, clues, and behavior.

## 🔎 What Can You Create?

### 🗺️ Treasure Hunts

Hide clues across your world and lead players toward a legendary treasure.

### 🏛️ Server Mysteries

Create an ongoing investigation surrounding your server's history, lore, or hidden locations.

### 🧩 Puzzle Adventures

Combine riddles, passwords, locations, items, and puzzles into one connected adventure.

### 🏆 Community Events

Create server-wide investigations where everyone works together—or competes to become the first solver.

### 📖 Story Adventures

Build branching narratives where player decisions determine what happens next.

## 🚀 Easy to Start

Create a mystery, add your stages, hide your clues, configure your rewards, and publish it.

```text
/mystery create
```

Then let the investigation begin.

```text
🕵️ A new mystery has begun...

"The Forgotten Founder"

Somewhere in this world,
something has been left behind.

Can you find it?
```
